# Messenger Task Capture Extension

## Installation

1. Download this repository as ZIP.
2. Unzip the file.
3. Open Brave or Chrome.
4. Go to:
   - Brave: `brave://extensions`
   - Chrome: `chrome://extensions`
5. Turn on Developer Mode.
6. Click Load Unpacked.
7. Select the `messenger-extension` folder.
8. Pin the extension.

## Login

1. Click the extension icon.
2. Enter your assigned email and password.
3. Click Login.
4. Wait for “Logged in as your@email.com”.

## Usage

1. Open Facebook or Messenger in browser.
2. Select the message text.
3. Right click.
4. Click Save to Tracker.
5. The task will appear in the dashboard.

## Important

Do not delete or move the `messenger-extension` folder after loading it.

If the extension stops working, go to the extensions page and click Reload.
